# 疟原虫血涂片制作与筛查 — 虚拟3D仿真实验

基于 Three.js 的网页版虚拟仿真实验，模拟疟疾诊断标准流程：**末梢采血 → 厚薄血膜制作 → 固定 → 吉姆萨染色 → 显微镜检查 → 虫种鉴定**，全程记录操作正误并生成成绩报告。

## 功能特性

- **7 个实验步骤**：器材准备、末梢采血、血膜制作（推片）、血膜固定、吉姆萨染色、显微镜检查、虫种鉴定
- **双模式**：教学模式（全程引导 + 知识讲解）/ 考核模式（无提示，计入成绩）
- **真实操作判定**：
  - 采血：消毒 → 待干 → 穿刺 → 弃第一滴血的顺序校验（酒精未干穿刺判溶血错误）
  - 推片：推片角度（30–45°）、拖动直线性、速度均匀性实时判定血膜质量
  - 固定：薄血膜甲醇固定、厚血膜禁止固定
  - 染色：计时染色，过早冲洗判着色不良
  - 镜检：10×→40×→100× 油镜流程，未滴香柏油禁用油镜
- **程序化镜检视野**：Canvas 实时绘制红细胞、白细胞与 4 种疟原虫（间日疟/恶性疟/三日疟/卵形疟）各发育期形态，随机生成病例
- **评分系统**：满分 100，错误操作明细分步扣分，成绩单可打印，历史记录存 localStorage

## 运行环境

- Node.js ≥ 18（开发）
- 现代浏览器（Chrome / Edge / Firefox），无需安装任何插件

## 快速开始

```bash
npm install        # 安装依赖（three + vite）
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 打包到 dist/（约 10MB，可部署到任意静态服务器）
npm run preview    # 本地预览打包结果
```

## 操作说明

| 操作 | 方式 |
|---|---|
| 旋转/缩放视角 | 鼠标拖拽 / 滚轮 |
| 使用器材 | 点击器材 → 点击作用对象 |
| 推片 | 拿起推片 → 点击玻片 → （薄血膜先调角度）按住拖动 |
| 镜检 | 拖拽移动视野 · 滑块调焦 · 点击虫体标记 |

## 技术架构

```
src/
├── core/       引擎封装(Engine)、射线交互(Interaction)、步骤状态机(StepManager)、评分(ScoreManager)
├── models/     程序化 3D 建模（载玻片/采血针/试剂瓶/显微镜/手指等，无外部模型文件）
├── scenes/     实验台场景
├── steps/      7 个实验步骤的操作逻辑与判定规则
├── microscopy/ 血膜视野渲染器 + 疟原虫形态学绘制 + 病例生成器
└── ui/         HUD、消息提示、成绩单
```

## 教学要点（评分点）

1. 器材选择：识别并选用正确器材（酒精灯、培养皿为干扰项）
2. 无菌操作：消毒 → 待干 → 穿刺；弃去第一滴血
3. 血膜质量：厚血膜约 1cm 圆斑；薄血膜 30–45° 匀速推成舌状
4. 固定原则：薄血膜甲醇固定，厚血膜不固定（需溶血）
5. 染色规范：吉姆萨染液足时染色后缓冲液冲洗
6. 镜检顺序：低倍 → 高倍 → 油镜（先滴香柏油）
7. 虫种鉴定：依据真实血涂片照片鉴别**间日疟原虫**（红细胞胀大、薛氏点、各期可见）与**恶性疟原虫**（小环状体、双核、新月形配子体）
